# iamTrans

영어 웹페이지를 한국어로 번역하는 몰입형(immersive) 크롬 확장 프로그램입니다.
페이지 레이아웃을 그대로 둔 채 문단 단위로 번역문을 끼워 넣고, 코드·수식·개발 도구 UI는 건드리지 않습니다.

## 기능

- **번역 엔진 3종**
  - **Chrome 내장 번역**: 무료, 기기 안에서 실행 (Chrome 138+ 데스크톱)
  - **DeepL**: API 키 필요 (Free / Pro 모두 지원)
  - **Claude**: API 키 필요, 모델 선택 가능 (기본 `claude-opus-5-5`, 저렴하게 쓰려면 `claude-haiku-5-5`)
- **표시 모드**
  - **영한 병렬**: 원문 아래에 번역문이 옅은 배경과 함께 표시됩니다. 글꼴·크기·색은 원문을 그대로 따릅니다.
  - **번역으로 대체**: 원문을 숨기고 번역문만 표시합니다. 모드 전환은 다시 번역하지 않고 즉시 바뀝니다.
- **서식 유지**: 링크, 굵게, 기울임, 색상 등 문장 안의 서식이 번역문에도 유지됩니다. 링크는 번역문에서도 클릭할 수 있습니다.
- **번역하지 않는 것**
  - 코드 블록(`pre`)과 인라인 코드(`code`, `kbd`): 문장은 번역하고 코드 조각은 원래대로 둡니다.
  - 수식: KaTeX, MathJax, MathML
  - 개발 도구 UI: CodeMirror, Monaco, Ace, xterm.js, 편집 가능한 영역
  - 입력창·버튼 등 폼 요소, `translate="no"` 또는 `.notranslate` 요소
  - 이미 한국어인 문단, 코드처럼 보이는 문단
- **비용 절약**: 화면에 보이는 부분만 번역하고, 스크롤하면 이어서 번역합니다.

## 설치

1. 이 저장소를 내려받습니다.
   ```sh
   git clone https://github.com/1ncarnati0n/iamTrans.git
   ```
2. 크롬에서 `chrome://extensions`를 열고 오른쪽 위 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 눌러 `iamTrans` 폴더를 선택합니다.
4. 설치 전에 열려 있던 탭은 새로고침해야 동작합니다.

## 사용법

1. 툴바의 iamTrans 아이콘을 눌러 팝업을 엽니다.
2. 엔진과 표시 모드를 고릅니다. DeepL·Claude는 API 키를 입력합니다(키는 이 브라우저에만 저장됩니다).
3. **번역**을 누르면 번역이 시작되고, **원문**을 누르면 원래대로 돌아갑니다.

**단축키** `Alt+A` (macOS는 `Option+A`)로 현재 페이지 번역을 켜고 끌 수 있습니다. 팝업에서 마지막으로 고른 엔진과 모드를 사용합니다.
다른 확장과 겹쳐 지정되지 않았거나 바꾸고 싶다면 `chrome://extensions/shortcuts`에서 설정하세요.

Chrome 내장 번역을 처음 쓸 때는 번역 모델을 내려받습니다(팝업에 진행률 표시).
사이트에서 처음 쓸 때 페이지 오른쪽 아래에 **시작** 버튼이 뜨면 한 번 눌러 주세요(크롬 보안 정책).

## 개발

빌드 과정 없는 Manifest V3 확장입니다.

| 파일 | 역할 |
|---|---|
| `manifest.json` | 확장 설정 |
| `content.js` / `content.css` | 페이지에서 번역할 블록 찾기, 번역문 렌더링 |
| `background.js` | DeepL / Claude API 호출 (API 키는 여기서만 읽음) |
| `popup.html` / `popup.js` | 설정 화면 |
| `lib.js` | 공용 순수 함수 (자리표시자, 휴리스틱) |
| `test.js` | 단위 검사: `node test.js` |

설계와 조사 내용은 [docs/PLAN.md](docs/PLAN.md)를 참고하세요.

## 알려진 한계

- 다른 블록을 포함한 `div`의 직접 텍스트는 번역하지 않습니다.
- Chrome 내장 번역은 서식 표시(`⟦0⟧` 등)를 잃을 수 있습니다. 이때 코드·수식은 문장 끝에 붙고, 링크·굵게 등은 일반 글자가 됩니다.
- iframe, Shadow DOM 안의 내용은 번역하지 않습니다.
- 원문 언어는 영어로 고정되어 있습니다.
